How it works

It knows whose pause it is.

01

Your voice, from the call's start

The first 10 s of speech in the call become the enrollment — a ReDimNet speaker embedding, computed once in 19 ms. No sign-up recording needed; one can be given instead.

02

Four ways to listen for you

The embedding enters voxturn's speech LLM (Qwen3-ASR-1.7B) as prompt tokens, as per-token voice matching, as a target-speaker VAD and inside the audio encoder. Training on counterfactual pairs — same audio, other enrollment, other answer — makes it compare voices instead of guessing "the louder one".

03

VAD speech isn't always yours

Pipecat's VAD fires on anyone. While it does, the plugin asks the model every 200 ms whether it is the user speaking; if not, that is the user's silence — so the turn can end while the bystander talks on.

Barge-in: should the agent stop talking? · while it speaks

Real two-party calls (TurnBench dev). The user's real interruptions and backchannels, and a bystander who starts talking, as loud as the user, close by or across the room. Each detector may stop for at most 10% of the user's backchannels. Hardest case: a bystander's real interruption close by (4.5%).

Cut-offs: the share of the user's pauses where the agent replies although the user goes on, at a 300 ms answer-latency budget (eot-bench protocol). The enrollment is ~10 s of the user's speech from elsewhere in the same call (phone) or from another meeting of theirs (DiPCo, AMI). Meeting numbers are high for every model: after a finished sentence, the other participants decide whether the floor passes.

Use it

One analyzer per call. No sign-up recording.

from pipecat_voxturn_personal import VoxTurnPersonalAnalyzer
from pipecat.turns.user_stop import TurnAnalyzerUserTurnStopStrategy
from pipecat.turns.user_turn_strategies import UserTurnStrategies

analyzer = VoxTurnPersonalAnalyzer()     # captures the user's voice from the call's start
strategies = UserTurnStrategies(stop=[TurnAnalyzerUserTurnStopStrategy(turn_analyzer=analyzer)])
from huggingface_hub import snapshot_download
import sys; path = snapshot_download("AustinXiao/voxturn-personal-turn-detector"); sys.path.insert(0, path)
from voxturn_personal import VoxTurnPersonal

model = VoxTurnPersonal.from_pretrained(path)
enr = model.call_enrollment()                  # once per call
user = enr.add(chunk, is_speech)               # every chunk, with your VAD's speech flag
model.predict(last_8s, user, questions=("eot", "target_active"))
# no GPU: the hosted demo on Hugging Face Spaces (pip install gradio_client)
from gradio_client import Client, handle_file

client = Client("AustinXiao/voxturn-demo")
client.predict(handle_file("user_voice.wav"),   # ~10 s of the user, or the call's start
               handle_file("audio_so_far.wav"), # others may talk
               False,                           # True while the agent speaks -> barge_in
               api_name="/personal_decide")
# {'eot': {...}, 'target_active': {'user': 0.02, 'other': 0.98, 'none': 0.0}, ...}

plot, s = client.predict(handle_file("call_start.wav"), handle_file("turn.wav"), "", 0.85, 0.8,
                         api_name="/personal_timeline")
s["reply_personal"], s["reply_v1"]              # when each model would reply

The hosted API takes several seconds per call (a GPU is allocated per call): use it to try ShadowMe; run the model yourself in a live agent. Arguments and outputs: model card.
